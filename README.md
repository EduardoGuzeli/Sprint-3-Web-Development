# 🚀 Sprint 3 — Web Development

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte da **Sprint 3 de Web Development**, com o objetivo de aplicar na prática os conhecimentos adquiridos durante a disciplina no desenvolvimento de uma aplicação web moderna, responsiva e funcional.

A aplicação foi desenvolvida utilizando **React.js** e **Vite**, buscando aplicar conceitos de componentização, organização de código, reutilização de elementos e desenvolvimento de interfaces web.

O projeto representa a evolução prática dos conhecimentos de desenvolvimento Front-End, utilizando tecnologias atuais do ecossistema JavaScript.

---

## 🎯 Objetivo

O principal objetivo deste projeto é desenvolver uma aplicação web utilizando **React**, colocando em prática conceitos fundamentais de desenvolvimento Front-End, como:

* Criação de componentes reutilizáveis;
* Organização e estruturação de projetos React;
* Desenvolvimento de interfaces responsivas;
* Utilização de JavaScript para lógica da aplicação;
* Gerenciamento de elementos da interface;
* Estruturação de páginas e componentes;
* Utilização de ferramentas modernas de desenvolvimento;
* Versionamento do projeto utilizando Git e GitHub.

---

## 💡 Proposta

A aplicação foi construída com foco em proporcionar uma experiência de usuário simples, intuitiva e organizada.

Durante o desenvolvimento, foram aplicados conceitos de **UI (User Interface)** e **UX (User Experience)**, buscando criar uma interface visualmente agradável e fácil de utilizar.

A estrutura do projeto também foi pensada para facilitar futuras alterações e evoluções da aplicação.

## ⚙️ Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

* **Node.js**
* **npm**
* **Git**

Para verificar se o Node.js está instalado:

```bash
node -v
```

Para verificar o npm:

```bash
npm -v
```

---

## 📥 Instalação

Clone o repositório utilizando:

```bash
git clone https://github.com/EduardoGuzeli/Sprint-3-Web-Development.git
```

Entre na pasta do projeto:

```bash
cd Sprint-3-Web-Development
```

Instale as dependências:

```bash
npm install
```

> A pasta `node_modules` é criada automaticamente após o `npm install`. Ela não precisa ser enviada para o GitHub, pois as dependências são definidas no `package.json`.

---

## ▶️ Executando o Projeto

Após instalar as dependências, execute:

```bash
npm run dev
```

O Vite iniciará o servidor de desenvolvimento e fornecerá um endereço local para acessar a aplicação pelo navegador.

Normalmente, o projeto poderá ser acessado em:

```text
http://localhost:5173
```
